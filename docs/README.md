## System Summary

The FIU Report Management System manages FIU reports for the STR Unit as a
**standalone program**: all data entry is manual, authentication is local
(username/password), and there are no external system integrations
(see [00_Scope_Amendment.md](00_Scope_Amendment.md)).

The system is deployed **on-premises only**.
